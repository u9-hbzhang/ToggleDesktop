# v1.2.0 更新说明

## 桌面图标状态同步优化
- 切换逻辑改为 Explorer 官方命令路径，和桌面右键菜单“显示桌面图标”保持同一状态源。
- 修复“隐藏图标后桌面右键菜单无法弹出”的问题，避免误隐藏桌面容器窗口。
- 新增外部状态监听：用户从桌面右键菜单手动切换显隐后，托盘状态会自动同步。
- 监听性能优化：1 秒轻量探测（注册表）+ 30 秒全量校准（窗口探测），兼顾实时性与资源占用。

## 收藏必应壁纸优化
- 优先保存“当前桌面正在显示”的必应壁纸，收藏结果与用户当前所见保持一致。
- 增强高分辨率下载策略，支持 UHD 优先和多候选地址回退，提高下载成功率与清晰度。
- 优化文件命名逻辑，修复日期前缀重复问题（如 `20260910_20260910_xxx`）。

## 发布资产说明
- 本次继续使用轻量发布形式：`ToggleDesktop.exe`、`ToggleDesktop.dll`、`ToggleDesktop.runtimeconfig.json`。
- 该形式不是 Debug 包，而是 Framework-dependent Release 包；运行需要本机已安装 .NET 8 Runtime。
